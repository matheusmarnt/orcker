### RED strategy (DT4)

Two shapes, both recorded below:

- **Natural RED** — the restored test fails, or fails to compile, before its
  rewiring. The error is the evidence.
- **Inversion RED** — a test that is green the instant it is restored proves
  nothing alone (SPEC-0002's own `backend_resolver.rs` finding). Invert the
  production guarantee it pins, capture `FAILED`, restore the code. Inversions
  cluster: one edit to a shared function reds every test that pins it.
