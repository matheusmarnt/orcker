## S5 — GREEN (round 2)

Round 1 was a REWORK, and the defect was in this cycle's own repair. The insert
was written as `cells[:5] + ['—','—','—'] + cells[5:]`, but index 4 of a split
row is `Cycle duration`, not `Attempts`. Every row shifted one column: `Escalates`
came to hold `1 session (<date>)` and `Cycle duration` — the one value the record
actually carried — was overwritten with `—`. R2 was violated in both directions
at once: a value invented for a column no log measured, and a recorded value
destroyed.

**AC1's original evidence could not have caught it.** It counted fields per row,
and a shift preserves the count. The supervisor found it by reading values against
their headers. AC1 now asserts per column, which is the check that fails when the
bug is present:

```
Attempts             ^[0-9]+$
Escalates            ^(—|[0-9]+)$
Gate time            ^(—|[0-9]+ ?m(in)?|[0-9]+ ?s)$
Pure-crate coverage  ^(—|[0-9.]+%)$
Cycle duration       ^(—|[0-9]+ sessions?.*)$
```

## Findings

- **F1 — the record had a third defect nobody had counted.** Markdown table cells
  cannot hold an unescaped `|`, and two regex alternations in the SPEC-0033 row
  silently added phantom columns. Any future row quoting a regex, a shell pipe or
  an alternation will do it again; the S8 step that appends a row should escape
  before writing.
- **F2 — the process does not instrument itself.** Three of section 11's four
  metrics were never captured by any cycle, so the columns start life empty. The
  gate does not emit its duration and nothing captures pure-crate coverage.
  Filling them from SPEC-0047 onward is a manual S8 obligation until something
  measures them; that instrumentation is deliberately **not** in this spec's
  surface and belongs in its own draft.
- **F3 — the one computable metric already breaches its target.** REWORK is 40%
  against `< 30%`. Section 11's own instruction for that case is "the specs are
  ambiguous: improve spec-writer, not the implementer" — material for the
  retrospective, not for this cycle to act on.
