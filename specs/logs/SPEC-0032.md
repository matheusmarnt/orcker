## S2 — root cause

Symptom: step 5 diffs a freshly built clippy-allow list against the checked-in
`scripts/clippy-allow-baseline.txt` and reports lines both added and removed.

A `+`/`-` pair for the *same* path means the file set is identical and only the
order differs. Confirmed by comparing the sets directly:

```
$ diff <(sort scripts/clippy-allow-baseline.txt) <(<fresh C-collated build> | sort)
$ echo $?
0
```

`scripts/gate.sh:34` piped through a bare `sort`, which honours `LC_COLLATE`.
Glibc's `pt_BR.UTF-8` collation follows ISO 14651 and treats `-` as variable,
ignored at primary strength: `bin/orcker-helper/...` compares as
`binorckerhelper...` and sorts *after* `bin/orckerd/...`. The C collation
compares raw bytes, where `-` is 0x2D and below every letter, so the same paths
sort *before*. Two legal orders for one file set; the baseline was generated on
this machine under `pt_BR.UTF-8`, so any C-locale machine fails the diff.

Not rename fallout. The bare `sort` is inherited from the bootstrap gate, and
the same failure would appear for any contributor whose locale is not C. It only
surfaced now because SPEC-0001 was the first cycle to run the gate in CI.

  branch per spec. This fix has to land on `feat/SPEC-0001-fork-bootstrap` to be
  useful: `main` has no `.github/workflows/gate.yml` at all (SPEC-0001 adds it),
