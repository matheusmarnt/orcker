## S1 — context

SPEC-0042 closed after three supervisor rounds, and all three named the same
hole: `draft -> approved` is the one transition SDD section 5 reserves for the
human, but nothing required it to exist in the **committed** record. That spec
reached `/spec-next` with `approved` present only as an uncommitted working-tree
edit of unknown authorship while `HEAD` said `draft`. The supervisor runs as a
subagent - it sees the repository, never the session - so an approval given
mid-cycle reaches it only as agent-authored prose, indistinguishable from an
approval the cycle invented.
